# 星火长明 · 两弹一星数字展馆

## 本地预览

解压后双击 `index.html`。数字讲解厅、历史档案和知识库均为静态页面。三栏首页在手机上自动改为上下布局。

- 数字讲解厅：选择章节后点击「开始讲解」。讲解开始时，人物口部播放模拟动作，字幕随语音逐句更新。
- 问答：输入年份、人物、工程名称或问题。系统从展馆资料中匹配条目，显示资料出处。可选择朗读回答。
- 历史档案：按时间浏览或筛选。每张展签是主题插图，点击图片可查看对应公开来源。
- 知识库：可组合使用关键词和章节筛选，展开条目查看正文和来源。
- 语音通过浏览器语音合成播放，优先使用设备上的普通话语音。音色及可用性取决于浏览器和操作系统。无法播放时可继续阅读文字。

## GitHub Pages

1. 新建一个独立的公开 GitHub 仓库，例如 `xinghuo-museum`。
2. 把本压缩包内的文件放在仓库根目录，保持 `assets/` 结构。确保 `index.html` 和 `.nojekyll` 位于根目录。
3. 在仓库打开 **Settings → Pages**。Source 选 **Deploy from a branch**，分支选 **main**，目录选 **/ (root)**，保存。
4. 等待 Pages 部署结束，以 Settings → Pages 显示的访问网址为准。

项目无需构建、服务端或 API 密钥。知识库数据位于 `data.js`，页面逻辑位于 `app.js`，样式位于 `style.css`。

历史档案使用国家航天局、中国载人航天工程网、中国科学院、国家发展改革委等公开资料。课堂资料整理自「昨天 · 自力更生」「今天 · 自主创新」「明天 · 自立自强」三组课件与讲稿。网站未附原始课件或讲稿文件。
